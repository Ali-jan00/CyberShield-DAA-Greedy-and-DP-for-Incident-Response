# CyberShield-DAA-Greedy-and-DP-for-Incident-Response
CyberShield is a defensive incident-response tool for a SOC facing ransomware with limited budget and time. Kruskal’s greedy MST builds the cheapest trusted monitoring backbone, skipping compromised links. A multi-window knapsack DP then schedules patches and fixes to maximize risk reduction. Simulated data only.
